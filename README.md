# malayu · 马来语学习

厦门大学马来西亚分校马来语公选课（MPU1012）配套学习工具，面向中文母语者。

## 在线使用

启用 GitHub Pages 后访问：

```
https://verity077.github.io/malayu/
```

## 功能

| 模块 | 说明 |
|---|---|
| 首次设定 | 选择从第几周开始（代表已有进度），更早周次直接进入复习库 |
| 顺序学习 | 按内容划分 13 个单元，按周次顺序推进 |
| 复习 | 所有学过的词统一进入复习库，每 10 个词一组，按艾宾浩斯曲线调度（1→2→4→7→15→30→60→120 天） |
| 图例 | 身体、家人等词条配课件截图，数字配大数字锚点 |
| 听写 | 数字、货币、时间、词语四类，随机出题，对应考试 Part A |
| 造句 | 词序重组，判分后给出逐词释义与语法说明 |
| 口语 | 听原音、录音回放，以及浏览器语音识别的发音评测 |
| 账号 | 邮箱登录（支持 6 位验证码），进度同步到云端；可自定义昵称与头像 |

## 内容来源

所有词条与例句取自课程课件，逐条标注出处与页码。课件未覆盖的知识点不写入内容。

## 本地运行

```bash
python3 -m http.server 8080
```

访问 <http://localhost:8080>

> 进度存在浏览器本地，按网址隔离。`file://`、`localhost`、局域网 IP 是三份互不相通的存档，建议固定用一个地址。

## 怎么用（普通用户）

1. 打开 <https://verity077.github.io/malayu/>
2. 直接开始学；不想登录也能用，进度存在本机
3. 想跨设备同步，点右上角「登录」→ 填邮箱 → 收邮件 → 填 6 位验证码

**普通用户不需要了解 Supabase，也不需要做任何配置。**

## 部署者说明：开启云端登录

> 这一节只给仓库维护者看。已经配好了，普通用户可以忽略。

默认配置下已经是云端模式。如果要在自己的 fork 里重新开启：

1. 建 Supabase 项目，执行建表 SQL
2. 在 `config.js` 填入 Project URL 与 anon key
3. 在 Supabase 的 URL Configuration 里填写本站地址
4. 在 Email Templates → Magic Link 里加入 `{{ .Token }}`，否则邮件里没有 6 位验证码

建表 SQL 与完整步骤见 [DEPLOY.md](DEPLOY.md)。
